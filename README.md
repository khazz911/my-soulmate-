# For My Soulmate Berti Saputri💕
A digital birthday letter dedicated to the most beautiful soul.
Built with love, memories, and countless prayers for someone truly special.

Terima kasih karena sudah bertahan sejauh ini.

Dan terima kasih karena tanpa sadar sudah menjadi alasan banyak kebahagiaan hadir.

Semoga tahun ini membawa lebih banyak tawa daripada air mata, lebih banyak pelukan daripada rasa sepi, dan lebih banyak momen indah yang bisa dikenang selamanya.

Happy Birthday Perempuan Kesayanganku🧣💕🎂
